# 🎲 Dice Roller

A simple browser-based dice rolling app built with HTML, CSS, and JavaScript. It lets users choose how many dice to roll and instantly displays the results with visual dice images.

## ✨ Features

- Select the number of dice to roll
- Generate random values from 1 to 6
- Display each result using dice images
- Lightweight and easy to run in any browser

## 📁 Project Structure

- `index.html` — main app layout
- `style.css` — styling and layout
- `script.js` — dice generation logic
- `assets/` — dice image files

## ▶️ How to Run

1. Open the project folder.
2. Launch `index.html` in your browser.
3. Enter the number of dice and click the roll button.

## 🧪 Example

If you enter `3`, the app may generate output like:

- 5, 2, 6
